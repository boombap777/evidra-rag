# 检索体验页设计与边界

目标：让访问者在一分钟内完成“载入样例—输入问题—阅读片段和来源”。
复用 Streamlit，不新增前端框架或独立 REST 层；查询与 MCP 共享同一核心 Factory、
Dense/HybridSearch、Reranker 和 Trace 类型，不另造一套排序算法。

信息层次：简短标题、真实运行模式、样例入口、单一查询表单、结果卡片。
集合与 Top-K 放入折叠设置；片段标识、阶段耗时与回退标记放入技术详情。
浅灰绿底色、深色正文、绿色主按钮；窄屏保持单列，避免大面积动画和指标墙。

必须覆盖初始、加载、空输入、空结果、成功和服务失败状态。显示的阶段来自实际 Trace；
错误不泄露异常细节，失败后不保留上一次结果冒充新结果。文档文本使用纯文本组件。
只允许显式离线演示向固定 publication_demo 集合加载自编样例；普通查询只读。
